# Проверка проекта глазами жюри — 23.09.2026

Проверяется опубликованная сборка `7309b63` в `feature/ui-readme` и уточнения README. Код приложения при этой проверке не изменялся.

## Обнаруженные проблемы

1. **Установка без ограничения транзитивных зависимостей не воспроизводится.** В новом окружении Python 3.11.9 на macOS команда `pip install -r requirements.txt` выбрала исходники PyArrow 25.0.1. Сборка зависимостей завершилась ошибкой отсутствующего Rust. Обновление pip с 24.0 до 26.2.1 не помогло. README исправлен на `pip install -r requirements.txt -c requirements.lock`: используется уже сохранённый PyArrow 17.0.0.
2. **Сборка отстаёт от веток участников.** В BUILD_SOURCES.json записаны core `8dc60a2` и ranking `c02f788`. На момент проверки удалённые ветки: core `7c0a191`, ranking `9a554ce`. Новые изменения требуют отдельной интеграции и повторной проверки. Нельзя называть ready_project автоматически актуальным объединением всех веток.
3. **Ошибка объяснения при другом регистре языка.** В реальном запросе `dense` заменить `language` на `РУССКИЙ` и `event_type` на `КОРПОРАТИВ`. Через recommend результат success, но карточка Куррапики пишет «запрошенный язык “РУССКИЙ” не указан в профиле»; факт формата также пропущен. Фильтры сравнивают без учёта регистра, объяснения — с учётом. В origin/feature/ranking соответствующее исправление уже есть. Перед сдачей интегратору перенести проверенное исправление с тестами в итоговую сборку. Обычная форма выбирает язык и формат из согласованного списка и не воспроизводит эту ошибку.
4. **Качество объяснений ещё требует ручной оценки.** Условия подтверждаются данными, но текст перегружен повторяющимися деталями. У Куррапики цитата про «современный подход» не даёт сильного доказательства отличия. У Мицури есть факт «сценарист» и запас 2 часа, но преимущество явно не сопоставлено с другими карточками. В README нет заявления о полном прохождении качественной приёмки.
5. **Документация команды расходится с реализацией.** Корневые docs/CHALLENGE_BRIEF.md и WORK_STATE.md всё ещё говорят об отсутствии выбранной задачи. TEAM_SPEC.md описывает целевой JSONL, фактическая сборка читает предоставленный CSV. Старый корневой app.py — отдельный этап интерфейса. В README указан один путь проверки: ready_project. Общие рабочие документы по AGENTS.md принадлежат интегратору.
6. **Выдача жюри.** Проверенный путь получения — SSH с доступом к репозиторию. Для эксперта без доступа нужен архив рабочей папки либо предоставленный доступ; не утверждать, что репозиторий общедоступен. Веса и кэш семантической модели не входят в сборку; основной запуск не использует нейросеть.

## Что исправлено в инструкции

Указан маршрут от установки до результата, команды Windows без ручного составления запуска, соответствие пяти имён CLI пяти пунктам интерфейса, отдельные команды всех сценариев и ожидаемые подписи. Объяснено, куда вводить данные, когда появляются карточки, как читать терминальный ответ, почему два пустых результата различаются. Синхронизированы оба README, ссылки проверены, TODO и CODEX VERIFY отсутствуют.

## Принятые решения

| Решение | Причина | Последствие |
|---|---|---|
| Pydantic для строгих схем, pytest для тестов | Популярные поддерживаемые MIT-библиотеки снижают риск ручной валидации и проверки | Точные версии закреплены в `requirements.txt` и `requirements.lock` |
| CSV и JSONL через единый загрузчик | Официальный CSV есть сейчас, JSONL назван в задании | Оба формата дают одинаковые нормализованные словари |
| Ranking не дублировать в ядре | Владение участника 2 и общий контракт | Интеграция проверяет состав, порядок карточек и сохранность исходных полей |
| Baseline по умолчанию; semantic — отдельное решение | Реальный semantic-кэш и модель отсутствуют в этой копии | Не заявлять AI готовым к сдаче; не подменять ошибку кэша скрытым fallback |
| Streamlit 1.58.0, общий lock на 52 пакета | Уже реализованный UI P3, source gate выполнен | Проверена установка Windows / Python 3.12; иные платформы не заявлены проверенными |

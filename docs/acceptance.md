Команды из корня проекта в новом окружении:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m pip check
python -m pytest -q -rs
python run_demo.py --verify
python -m streamlit run app.py --server.address 127.0.0.1 --server.headless true --browser.gatherUsageStats false --server.port 8504
```

Сервер работает до `Ctrl+C`. Проверка health выполняется из другого терминала: `curl --fail --silent http://127.0.0.1:8504/_stcore/health`. Health подтверждает запуск сервера; реальные пользовательские действия отдельно проверяются AppTest.

## Границы приёмки

| Проверка | Статус |
|---|---|
| Визуальная оценка браузерного экрана человеком | Не выполнена |
| Понятность и различимость объяснений без имён | Не выполнена; сценарий в [demo.md](demo.md) |
| Повторная установка итоговой сборки на Windows/Linux | Не выполнена в этой финальной проверке |
| Доступ жюри к репозиторию или переданному архиву | Требует проверки командой |
| Доставка semantic-кэша на машину демонстрации | Не выполнена; базовый запуск использует baseline |

Baseline не вызывает нейросеть: сортировка по начальной цене, лексический выбор цитат, объяснения по фактам. Дополнительный semantic-режим использует подготовленные embeddings. В Git есть CLI подготовки кэша v2, но нет весов модели и самого кэша; инструкции и отдельные эксперименты — в [ranking_notes.md](ranking_notes.md). Optional-проверки с этими артефактами не должны объявляться пройденными, если артефакты не предоставлены.

Тесты подтверждают согласованность с каталогом, но не достоверность его исходных утверждений. Цена «от» не является сметой, отсутствие даты в календаре не является подтверждением брони; синтетические и проставленные поля явно отмечаются.

## Передача участнику 1 — готово для копирования

> UI в app.py вызывает `data_loader.load_contractors(path)` и `recommender.recommend(query, contractors)` по TEAM_SPEC. Дата ISO, optional=None. Срез TOP-3, фильтрация, ranking и сообщения остаются у ядра. UI отображает `results`, `message`, `stats`, `rejections`, `meta` без пересортировки. Для подключения нужны ваши модули, согласованный JSONL и общие зависимости. Проверенные зависимости нашей части: `streamlit==1.58.0`, `pytest==9.1.1`. Общий requirements.txt я не менял. По умолчанию путь — `hackathon-dataset-anonymized.jsonl` рядом с app.py; другой путь через CONTRACTORS_DATA. После подключения нужны все три бизнес-статуса, полные boolean-флаги карточек, причины конкретных исключений и реальные версии в meta.

Источника JSONL в просмотренном проекте нет. CSV находится в `docs/`; решение о контролируемой конвертации или получении оригинального JSONL принимает владелец данных. UI не создаёт второй загрузчик.

# Демо объединённой сборки

Единственная реализация — в корне репозитория; инструкции запуска в [README](../README.md).
Полные запросы, ответы и исходные замеры P3 находятся в [demo_queries.json](../demo_queries.json).
Это реальные результаты baseline, не тестовые заглушки. После интеграции `8e5e1df` все пять ответов повторно совпали полностью.

```powershell
.\.venv\Scripts\python.exe run_demo.py --verify
```

В UI выберите готовый пример и нажмите кнопку подбора:
dense — 6 допустимых, показаны 3; date_b — 3 допустимых; rare — 2; no_match — 0 из 10; missing_category — группа отсутствует.
В паре dense/date_b меняется только дата. HK-88430 и HK-44923 исключены на 08.10 из-за busy_dates.

Для ручной приёмки скрыть имена в заголовках и цитатах, проверить полезность и различимость объяснений.
Техническое совпадение ответов не означает завершённую человеческую приёмку.

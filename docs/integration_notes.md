## Что осталось владельцам

**Участнику 3:** обновить README и сохранить полные реальные ответы пяти
сценариев в свои демо-артефакты. Их текущий текст «ядро отсутствует / JSONL
блокирует запуск» устарел. В этом интеграционном изменении README,
`demo_queries.json`, `docs/demo.md` и `docs/acceptance.md` не переписывались.
Таблица выше — проверка интеграции, не замена сохранённым демо и ручной приёмке.

**Человеческая приёмка не выполнена:** скрыть имена не только в заголовках,
но и в цитатах описаний; проверить отличимость и полезность объяснений.
Уникальность строк в тестах не доказывает их смысловую полезность.

**Участнику 2, нормализация:** выявлен воспроизводимый дефект API даже в baseline:
запрос `dense` с `language="РУССКИЙ"` проходит фильтр, но объяснение HK-88430
ошибочно говорит, что язык не указан. UI отправляет канонические значения,
поэтому пять UI-сценариев этого дефекта не вызывают. Нужны одинаковые правила
`strip/casefold` для сравнений условий в ядре и объяснениях, с сохранением
исходных значений для показа. Production-модули участника 2 здесь не менялись.

**Если команда выбирает semantic:** режим пока не включён в итоговую сборку.
Кэш из временного каталога на машине P2 не является доступным артефактом этой копии.
P2 + P1 должны передать кэш с проверяемым SHA-256, закреплёнными моделью/revision
и encoder-зависимостями, обеспечить воспроизводимую подготовку и покрытие
всех допустимых сочетаний формат/категория из UI. `semantic.query_text` сейчас
зависит от регистра; изменение нормализации требует согласованной версии
текста, пересборки кэша и повторных тестов. Нет кэша/нужного ключа — явная
ошибка, не скрытый переход на baseline. После этого выполнить 3 optional-теста
и те же сквозные UI-сценарии в выбранном режиме.

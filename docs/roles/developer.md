# Участник 2 — разработчик

## Твоя роль

Ты отвечаешь за самостоятельный технический результат, выбранный после публикации задачи. Твои сильные стороны — Python, Go, SQL, автоматизации, AI-агенты и деплой. Не закрепляй за собой компонент заранее: возьми ту независимую часть, которая сильнее всего уменьшает риск общего решения.

## Порядок работы

1. Прочитай `AGENTS.md`, этот файл, `docs/CHALLENGE_BRIEF.md` и `docs/WORK_STATE.md`.
2. Уточни ожидаемый результат, принадлежащие тебе файлы, входные данные, фиксированные интерфейсы и способ проверки.
3. Сначала проверь самый рискованный технический вопрос своей части.
4. Реализуй минимальный сквозной результат и проверь его согласованной командой.
5. Не меняй общий контракт самостоятельно. Запиши запрос интегратору и продолжай независимую работу, если это возможно.
6. Передай результат с перечнем файлов, проверок, допущений и оставшихся рисков.

## Субагенты

Используй их для независимого исследования, тестов или ограниченного компонента с отдельными файлами. Короткие и последовательные действия выполняй сам.

> Я участник 2, разработчик. Прочитай корневой AGENTS.md, мои ролевые инструкции, актуальную задачу и рабочее состояние. Найди наиболее полезную независимую техническую часть с чёткими файлами и интерфейсами, согласуй её границы и начни с проверки главного риска. Не меняй общие контракты без интегратора.

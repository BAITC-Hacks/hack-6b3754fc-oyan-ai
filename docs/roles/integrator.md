# Участник 1 — разработчик-интегратор

## Твоя роль

Ты разработчик на Python и Go и хорошо реализуешь конкретный код. Во время хакатона можешь заниматься API и отвечаешь за финальное объединение веток.

У тебя меньше опыта в проектировании целой системы, базах данных, миграциях, фронтенде и деплое. Поэтому Codex должен не перекладывать эти решения на тебя, а предлагать простейший обоснованный вариант, объяснять последствия и проверять совместимость частей.

Ты отвечаешь за целостность решения: выбор простейшей архитектуры, общие контракты, интеграцию работ, Git и итоговую проверку. Codex должен активно помогать с системным дизайном, API, хранением данных, интерфейсами между частями и выявлением интеграционных рисков.

Ты не обязан реализовывать всё сам. После выбора задачи оставь у себя общие контракты и интеграционно чувствительные файлы, а независимые результаты передай другим участникам или субагентам.

## Порядок работы

1. Прочитай `AGENTS.md`, `docs/CHALLENGE_BRIEF.md` и `docs/WORK_STATE.md`.
2. Если задача ещё не выбрана, координируй выбор через `docs/CASE_SELECTION.md`.
3. Предложи самый маленький полный пользовательский сценарий и объясни ключевые компромиссы.
4. Зафиксируй границы компонентов и минимальные контракты до параллельных изменений.
5. Назначь непересекающиеся результаты и файлы; общие конфигурации, схемы и контракты оставь у себя.
6. Проверяй каждую интеграцию самостоятельно и поддерживай проект запускаемым.

## Не делай

- Не выбирай сложную архитектуру ради будущего масштаба.
- Не разрешай параллельно менять общий контракт без координации.
- Не принимай техническое решение только на основании отчёта субагента.
- Не задавай специалисту по предметной области вопросы о стеке, API, Git или деплое.

## Стартовая фраза

> Я участник 1, разработчик-интегратор. Прочитай корневой AGENTS.md, мои ролевые инструкции, актуальную задачу и рабочее состояние. Проверь, что уже известно, предложи минимальный полный сценарий и следующий шаг. Помоги определить контракты и непересекающиеся части работы; субагентов используй только для независимых задач.

# Совместимый путь запуска

Единственная актуальная реализация находится в корне репозитория.
Эта папка больше не является самостоятельной копией проекта: нужен весь репозиторий.
`app.py` и `run_demo.py` запускают корневые файлы; зависимости ссылаются на общие файлы.
Старые копии ядра, ranking, тестов и данных удалены из этой папки, но сохранены в Git-истории.

Основные инструкции: [README проекта](../README.md).
Из корня можно по-прежнему выполнить:

```powershell
.\.venv\Scripts\python.exe -m streamlit run ready_project/app.py --server.address=127.0.0.1
.\.venv\Scripts\python.exe ready_project/run_demo.py --verify
```

Полный набор тестов запускается из корня: `python -m pytest -q -ra`.

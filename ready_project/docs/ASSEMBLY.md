# Сборка единого проекта

Эта папка самостоятельна: она содержит приложение, ядро, ранжирование, данные, тесты и документацию. Родительский проект для запуска не нужен. Инструкция установки и проверки находится в единственном `README.md` в корне репозитория; при передаче архива приложите его рядом с этой папкой.

Источники команды записаны в `BUILD_SOURCES.json`:

- участник 1: contracts.py, data_loader.py, recommender.py и тесты загрузки/ядра;
- участник 2: ranking.py, scoring.py, semantic.py, explanations.py и их тесты;
- участник 3: app.py и UI-тесты.

Изменения при сборке:

1. Путь данных по умолчанию в app.py указывает на включённый официальный CSV. Загрузчик участника 1 уже поддерживает CSV и JSONL; данные не переписывались.
2. В UI добавлен выбор сохранённого demo-запроса. Он только заполняет форму; результат всегда вычисляется настоящим recommend.
3. Тест отсутствующего ranking из изолированной ветки ядра теперь явно моделирует отсутствие модуля через monkeypatch. В общей сборке модуль присутствует.
4. Добавлены run_demo.py, проверенные снимки ответов и тесты полного пути на настоящем каталоге.
5. Объединены зависимости частей. Для запуска используется baseline без модели и без внешнего API. Optional semantic-модуль сохранён; без кэша он не объявляется работающим AI.

Приёмка качества объяснений человеком остаётся отдельным действием: тесты проверяют происхождение цитат и условия, но не заменяют оценку понятности.

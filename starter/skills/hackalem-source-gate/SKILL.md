# HackAlem source and dependency gate

Prevent weak evidence, abandoned packages, and copied solutions from entering a five-hour project.

- For domain, API, model, or dataset research, read [references/research.md](references/research.md).
- Before adding a framework, package, repository, binary, or hosted service, read [references/dependencies.md](references/dependencies.md).
- When both apply, run research first and dependency approval second.

Return a compact decision with evidence links, access date, uncertainties, and an explicit `approve`, `approve with fallback`, or `reject`. Do not install, copy, or integrate the candidate until approved.
